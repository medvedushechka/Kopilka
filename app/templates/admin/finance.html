Как это должно работать в реале

architecture
1. Пополнение инвестораБанк/платёжный провайдер → TEST-кошелёк → ledger-запись.
2. ИнвестицияКошелёк займодавца → escrow инвестиций + комиссия Kopilka.
3. Полное финансированиеEscrow → выплата заёмщику через банк-партнёр.
4. ПогашениеЗаёмщик → платёжный шлюз → распределение между займодавцами.
5. СверкаGateway operations + wallet transactions + ledger entries должны сходиться.
